# 금지어 사전: 성아여고 집필 스타일 가이드 (한국어 번안판)

> 원본: *BANNED — THE DEFINITIVE GUIDE* (영어 산문용 개인 스타일 가이드, 4부 구성)
> **이 문서는 원본의 "Part 4: Erotica-Specific Guidelines"(성인물 전용 규정)를 전면 삭제하고, Part 1~3(구문·어휘·집필 원칙)만 한국어 서사·성아여고 세계관에 맞게 번안한 판본이다.** 성적인 내용은 어떤 형태로도 포함하지 않는다.
> 목적: 이 프로젝트의 글(본편, 외전, 게임 대사 등)을 쓸 때 Claude를 포함한 협업자가 참고하는 산문 체크리스트.

---

## 0. 사용 원칙

- 이 문서는 "이 표현을 쓰면 나쁜 글"이라는 절대 규정이 아니다. **"내가 게을러졌을 때 걸러내는 필터"**다.
- 여기 실린 대부분의 패턴은 한 번 쓰인다고 곧장 문제가 되진 않는다. **진짜 문제는 누적**이다. 같은 구문·같은 신체 텔·같은 비유가 여러 캐릭터·여러 장면에 걸쳐 반복되면, 글은 "교체 가능한 부품으로 조립된 글"처럼 읽힌다.
- AI가 생성한 글이 AI 같아 보이는 이유도 같다 — 통계적으로 가장 흔한 표현을 매번 고르기 때문에, 캐릭터마다 다른 반응을 보여야 한다는 걸 모른다. 사람도 같은 함정에 빠진다: 손에 잡히는 첫 표현을 습관적으로 쓰는 것.
- **적발 기준은 "반사적으로, 반복적으로, 교체 가능하게 썼는가"**다. 한 번의 "턱을 앙다물었다"는 괜찮다. 열 페이지 안에 다섯 번째 등장하는 "턱을 앙다물었다"는 패턴이다.

## 1부. 구문·구조 패턴 (성아여고 캐릭터들의 개성 있는 말투·문체를 해치는 기계적 리듬들)

**핵심 원칙:** 아래 패턴들은 전부 형식으로 내용을 대체한다. 고치는 방법은 항상 같다 — **실제로 무슨 일이 일어나는지 구체적으로 명명하거나, 결과를 보여주거나, 그냥 잘라낸다.**

| # | 패턴 | 한국어에서 흔한 형태 | 왜 실패하는가 | 수정 방향 |
|---|---|---|---|---|
| 1.1 | 순차 동작 쌍 | "~했다, 그리고 ~했다"의 기계적 반복 | 모든 동작이 똑같은 리듬으로 읽혀 로봇처럼 느껴짐 | 감정적 전환을 담거나, 아예 다른 문장 구조로 |
| 1.2 | 모호한 내면 플레이스홀더 | "뭔가가 가슴에서 조여왔다" / "눈빛 속에서 무언가 스쳤다" | "뭔가"는 작가도 뭘 묘사할지 모른다는 신호 | 정확히 무엇이 일어났는지 명명 |
| 1.3 | 의인화된 침묵 | "침묵이 두 사람 사이에 내려앉았다" | 침묵을 행위자로 만들고 결과는 안 보여줌 | 누가 침묵을 깨는지, 그 대가는 뭔지로 대체 |
| 1.4 | 부정 공식 | "화난 게 아니라 체념한 거였다" | 확답을 피하는 헤징. 반복되면 모든 감정이 같은 틀로 처리됨 | 직접 명명할 수 있는지 자문 |
| 1.5 | 3단 나열 | "피로. 외로움. 인내." | 구조로만 시적 진지함을 흉내냄 | 실제로 긴장을 쌓는 중인지, 그냥 연기하는 중인지 점검 |
| 1.6 | 스타카토 동사 조각 | "멈춘다. 다가간다. 물러선다." | 고조된 장면에서 과용되면 인위적으로 느껴짐 | 자연스러운 움직임으로 |
| 1.7 | 접속사 문장 시작 남용 | "그리고 그는 안다." / "하지만 그녀는 떠날 수 없다." | 과용하면 목소리가 평평해지고 가짜 리듬 생성 | 정말 극적 분리가 필요한지 점검 |
| 1.8 | 독립된 "왜냐하면" 조각 | "왜냐하면 차마 볼 수 없었으니까." | 친밀한 어조만 흉내내는 축약된 설명 | 행동으로 이유를 보여주기 |
| 1.9 | 헤지된 반응 | "웃음 같지 않은 웃음" / "미소라기엔 애매한 미소" | 독자가 실제 동작을 상상할 수 없음 | 그 제스처가 실제로 뭘 하는지 묘사 |
| 1.10 | 메아리 문장 | "그는 닿고 싶었다. 그는 보여지고 싶었다." | 평행 구조로 가짜 깊이 연출. 둘째 문장이 정보를 안 더함 | 둘째 문장이 발전시키는지 점검, 아니면 병합 |
| 1.11 | 무드 소품 부정 | "필요 없는 간장을 집어들었다" | 겉보기만 구체적일 뿐, 실제로는 아무것도 안 드러냄 | 이 행동이 왜, 뭘 드러내는지 없으면 삭제 |
| 1.12 | 메타서사 침입 | "장면은 아직 끝나지 않았다" | 캐릭터 시점을 벗어나 작가의 손이 보임 | 행동을 통해 다시 캐릭터 시점으로 |
| 1.13 | 분위기 선행 배치 | 날씨·교정 풍경으로 장면 시작 | 캐릭터보다 세트 장식이 먼저 나옴 | 캐릭터로 시작 |
| 1.14 | 중력 은유 | "그에게 끌렸다", "중력처럼" | 끌림을 자동현상으로 만들어 의지를 지움 | 선택으로 표현 |
| 1.15 | 부유 문구 | "말이 허공에 걸렸다" | 반복하면 무감각해짐. 정체만 만들고 결과가 없음 | 그 다음에 무슨 일이 일어나는지로 대체 |
| 1.16 | 충격 직유 | "가슴을 한 대 얻어맞은 것 같았다" | 클리셰에 의존, 모든 폭로가 똑같이 느껴짐 | 실제 신체 감각을 직접 묘사 |
| 1.17 | 물결/정적 직유 | "고요한 물에 던져진 돌처럼" | 죽은 비유. 감각적 근거가 없어 보이지 않음 | 충격을 직접 보여주기 |
| 1.18 | 정밀/통제 클러스터 | "외과의 같은 정확함", "노련한 손놀림" | 캐릭터를 능력 과시로 축소, 실제 동작이 안 보임 | 구체적으로 뭘 하는지 |
| 1.19 | 질감 기본값 | 목소리·태도를 "벨벳", "강철", "대리석"으로 | 너무 흔해서 이제는 안 보임 | 다른 질감을 찾거나 실제 감각 묘사 |
| 1.20 | 공허한 욕망 진술 | "그를 원했다. 신이시여, 원했다." | 심리적 근거 없는 욕구는 어느 캐릭터에도 붙을 수 있음 | 무엇을, 왜 원하는지 구체화 |
| 1.21 | 대리 전달 | "말없이도 통했다", "눈빛이 모든 걸 말했다" | 실제 소통 내용을 안 보여주는 서사적 게으름 | 실제로 뭐가 전달됐는지 보여주기 |
| 1.22 | 공허한 억제 | "그는 참았다", "삼켰다" | 뭘 억누르는지 안 밝히는 추상적 억압 묘사 | 정확히 뭘 참는지, 참는 방식은 뭔지 |
| 1.23 | 미화된 손상 | "며칠째 못 잤다", "술로 버텼다" | 자기파괴를 미화. 깊이 대신 어둠으로 때움 | 그 대가를 실제로 보여주는지 점검 |
| 1.24 | 사이비 지적 아포리즘 | "결국 우리는 다 이야기일 뿐이야" 류의 명언체 대사 | 실제 위기 상황에서 아무도 이렇게 말하지 않음 | 이 캐릭터가 이 순간 실제로 할 생각인지 |
| 1.25 | 오용된 서사시적 톤 | "그 순간 뭔가가 영원히 부서졌다" | 사소한 순간을 절정처럼 과장, 균형이 무너짐 | 실제로 그렇게 큰 순간인지 축소 검토 |
| 1.26 | 우아한 변주 | 이름 대신 "그 나이든 남자" / "그 젊은 여자"로 순환 | 반복 회피가 오히려 눈에 띔, 인물을 인구통계로 축소 | 수식어가 실제 기능(시점·거리감)을 하지 않으면 이름 사용 |
| 1.27 | 거짓 범위 구성 | "첫 키스의 친밀함에서 침묵의 건축까지" | 척도가 안 맞는 두 끝을 이어 포괄적으로 들리게만 함 | 실제 중간 지점이 있는지 확인, 없으면 삭제 |
| 1.28 | 피상적 해석 서술 | "그녀는 방을 나섰다, 좌절감을 드러내며" | 서술자가 개입해 행동의 의미를 설명해버림 | 행동 자체가 의미를 담도록 재구성 |
| 1.29 | 부정 병렬 | "단지 침묵이 아니라, 침묵이 담은 모든 것이었다" | 구문적 대조로 심오함을 연기. 둘째 절이 과장된 반복인 경우가 많음 | 정보를 더하는지 확인, 아니면 직접 진술 |
| 1.30 | 직유-부사 | "포위전을 준비하는 사람의 결연함으로" | 가상의 인물을 만들어 실제 인물 상태를 설명 | 실제 행동·감정을 직접 묘사 |
| 1.31 | 늘어지는 분사구문 연속 | "~했다, ~하며", 3문장 이상 연속 | 모든 문장이 같은 리듬. 동시에 일어날 수 없는 동작을 동시처럼 묘사하게 됨 | 구조를 바꾸거나 분사구를 독립 문장으로 분리 |

## 2부. 단어·구절 (빠른 스캔용)

Part 1이 "문장 구조"의 문제라면, 이건 **개별 단어·관용구** 수준의 문제다. 검색해서 걸리면 아래 방향으로 고친다.

| 검색어(한국어 대응) | 문제 유형 | 수정 방향 |
|---|---|---|
| 턱 (앙다물다) / 목 (메다, 잠기다) / 주먹 (쥐다) | 신체 텔(감정 대체) — 만능 클리셰 | 이 캐릭터만의 구체적 반응으로 |
| 숨 (막히다/삼키다/터지다) | 신체 텔 남용 | 장면 템포나 힘의 균형을 바꿀 때만 사용 |
| 뭔가 + 흔들리다/무너지다/바뀌다 | 모호한 내면 플레이스홀더 | 실제로 무슨 일이 일어나는지 명명 |
| "원초적인" / "날것의" | 기본 감정 서술어 | 실제 감정을 정확히 명명 |
| "조심스럽게" | 막연한 부사 | 조심하는 이유·안 그러면 어떻게 되는지로 구체화 |
| "마침내" | 전환 플레이스홀더 | 누가 먼저 꺾이는지 보여주기 |
| "그 무게" | 추상 명사 남발 | 실제 반응으로 결과를 보여주기 |
| "잠시" / "한 박자" | 시간 필러 | 삭제하거나 실제 행동으로 |
| 침묵이 + 늘어지다/내려앉다/무겁다 | 의인화된 침묵 | 효과를 행동으로 보여주기 |
| "~에 얻어맞은 것 같았다" | 충격 직유 클리셰 | 실제 신체 감각 직접 묘사 |
| "그 필요/갈증" (대상 없이) | 공허한 욕망 | 무엇을 원하는지 구체화 |
| "~하지 않았다" (동작 없이 끝남) | 무동작 결말 | 행동으로 끝내거나 그 앞에서 자르기 |
| "아, 맙소사" 류 감탄 | 종교적 감탄사 남발 | 삭제 |
| "쉰(목소리)" / "갈라진" (남발) | 음성 묘사 클리셰 | 거칠다/낮다/찢어지듯 등 다른 표현으로 |
| "외과의 같은" / "노련한" | 정밀·통제 클러스터 | 실제 동작 묘사 |
| "강철 같은" / "벨벳 같은" | 질감 기본값 | 다른 질감이나 감각 묘사 |
| "그리고 지금은 그걸로 충분했다" | 얼버무린 결말 클리셰 | 실제 마무리 비트를 찾기 |
| "파고들다" / "태피스트리" / "풍경" (은유적) | AI 어휘 클러스터 | 구체적이고 캐릭터에 근거한 표현으로 |
| "부각시키며" / "강조하며" (분사구) | 서술자 개입형 해설 | 삭제 — 행동 자체가 말하게 하기 |
| "중요한" / "결정적인" / "핵심적인" (근거 없이) | 과장된 중요성 부여 | 행동을 통해 중요성을 얻게 하기 |
| "자리한" / "자랑하는" / "생기 넘치는" | 홍보성 문구 | 삭제 |
| "뿌리내린" / "닻을 내린" / "매인" (안정감 은유) | 정박 은유 기본값 | 다른 안정감 표현이나 행동으로 |
| "익숙한" / "평소의" / "루틴" | 막연한 습관 서술 | 실제 패턴을 구체적으로 명시하거나 삭제 |
| "순식간에 지나갔다" / "시간 가는 줄 몰랐다" | 시간 생략 필러 | 그 시간이 중요하면 보여주고, 아니면 그냥 다음 장면으로 |

> 위 표는 원본 2부(2.1~2.38, 총 38개 세부 카테고리)의 빠른 스캔 표를 한국어 서사에 맞게 압축·번안한 것이다. 신체 텔·직유·과장된 형용사 계열은 한국 웹소설·순정 서사에서도 거의 동일한 형태로 반복되므로(턱/목/주먹, 벨벳 목소리, "무언가" 등) 원본 패턴이 대부분 그대로 적용된다.

## 3부. 운영 지침

### 3.1 근본 문제

위 모든 금지 요소는 같은 이유로 실패한다:

- **창조 대신 흉내만 낸다** — 문학적으로 들리는 의미 없는 리듬, 감정처럼 보이는 빈 제스처.
- **교체 가능하다** — 어떤 이야기, 어떤 캐릭터에도 붙을 수 있어서, 이 순간 이 인물에 대해 아무것도 말해주지 않는다.
- **보여주지 않고 말한다** — 감정이 일어났다고 라벨만 붙이고 극화하지 않는다.
- **익숙함에 안주한다** — 가장 먼저 떠오르는 표현을 그대로 쓴다.

**핵심은 누적이다.** "턱이 굳었다"를 한 번 쓰는 건 괜찮다. 같은 구문·같은 신체 텔·같은 모호한 내면 묘사가 캐릭터를 가리지 않고 반복되면, 글은 "교체 가능한 부품 더미"처럼 읽힌다. 이게 진짜 AI 티다 — 문제는 **기본값의 밀도**다.

**점검 질문:** 최근 10페이지 안에 이걸 몇 번 썼는가? 여러 캐릭터에 교체 가능하게 썼는가? 처음 등장(괜찮을 수 있음)인가, 다섯 번째(패턴)인가?

**반례:** 개별 구문을 사냥하듯 지적하는 것도 무의미하다. 판단 기준은 "반사적으로, 반복적으로, 교체 가능하게 썼는가"다.

### 3.2 교정 프레임워크

| 상황 | 질문 |
|---|---|
| 신체 텔 | 이 특정 캐릭터는 이 감정을 어떻게 드러내는가? 이 인물만의 배출구는? |
| 모호한 내면 | 실제로 무슨 일이 일어나는가? 관찰자라면 뭘 볼까? 캐릭터는 신체적으로 뭘 느끼거나 구체적으로 무슨 생각을 하는가? |
| 은유 | 이 비교가 명확하게 하는가, 장식만 하는가? |
| 대화 태그 | 대사가 스스로 톤을 전달하는가? 수식어를 지워도 독자가 전달 방식을 알 수 있는가? |
| 전환/공백 | 이 정적 동안 무슨 일이 일어나는가? 누가 먼저 깨는가? 기다림의 대가는? |
| 결말 | 이 비트를 닫는 행동·결정·결과는 무엇인가? 방금 일어난 일로 무엇이 바뀌는가? |

### 3.3 대신 이렇게

- **막연한 신체 텔 대신:** 캐릭터별 구체적 스트레스 반응을 정하고, 심리와 연결하고, 대처 패턴을 드러내는 전치 행동을 보여준다.
- **막연한 감정 단어 대신:** 분노·두려움·슬픔·수치·욕망 등 구체적 감정을 명명하고, 그에 동반되는 사고 패턴과 행동적 결과를 보여준다.
- **죽은 은유 대신:** 감각을 직접 묘사하거나, 캐릭터 고유의 준거틀에 비유를 근거시키거나, 직접 묘사가 낫다면 은유를 아예 자른다.
- **분위기 선행 배치 대신:** 캐릭터의 행동·결정으로 시작하고, 환경은 캐릭터의 지각을 통해 도입한다 (카메라 팬 연출은 지양).
- **정적인 결말 대신:** 감정 상태를 응축하는 미세 행동으로 끝내거나, 역동을 바꾸는 대사로 닫거나, 가짜 심오함이 오기 전에 장면을 일찍 자른다.
- **메아리 문장 대신:** 둘째 문장이 정보를 안 더하면 자르고, 실제 움직임이 있는 한 문장으로 합친다. 고조시키거나, 복잡하게 만들거나, 모순시켜라 — 그냥 바꿔 말하지 마라.

### 3.4 초고 전 점검

**구조:**
- [ ] "~하고 ~했다"의 기계적 반복에 의존하지 않는다
- [ ] 3단 나열이나 스타카토 조각으로 거짓 강조를 만들지 않는다
- [ ] 캐릭터의 존재로 시작한다 (분위기 연출 샷 금지)
- [ ] 행동·결정·결과로 끝낸다 (정적이나 요약으로 마무리하지 않기)

**언어:**
- [ ] 대화 태그에 부사를 쓰지 않는다
- [ ] "뭔가"를 감정 플레이스홀더로 쓰지 않는다
- [ ] 침묵·공기·분위기를 능동적 힘처럼 묘사하지 않는다
- [ ] "날것의", "그 무게", "그 필요" 대신 구체적 감정을 명명한다

**신체 묘사:**
- [ ] 각 캐릭터가 긴장·욕망·억제에 대해 서로 다른 신체 텔을 가진다
- [ ] 턱/목/손 클리셰에 기본값으로 의존하지 않는다
- [ ] 호흡 묘사는 장면 템포나 힘의 균형을 바꿀 때만 사용한다

**은유:**
- [ ] 끌림을 중력 언어로 표현하지 않는다
- [ ] 온도를 감정의 약칭으로 쓰지 않는다
- [ ] 죽은 직유(물에 던진 돌, 물리적 충격, 허공에 걸림)를 쓰지 않는다
- [ ] 모든 비교는 명확화 목적으로만 쓴다

### 3.5 집필 중 즉시 점검

아래 표현을 쓰는 순간 멈추고 자문한다:

| 쓰고 있다면... | 멈추고 물을 것 |
|---|---|
| "~하고, ~했다" | 이 순서가 심리를 드러내는가, 그냥 동작을 안무하는 건가? |
| "뭔가" | 정확히 무슨 일이 일어나는가? |
| "침묵이 늘어지다/내려앉다" | 누구에게 어떤 효과가 있는가? |
| "~가 아니라 ~였다" | 이건 실제로 뭔가? 단정할 수 있는가? |
| "말했다" + 부사 | 대사가 스스로 톤을 전달하는가? |
| "목소리가 떨어지다/조여지다" | 리듬이나 행동으로 보여줄 수 있는가? |
| 턱/목/손의 긴장 | 이 캐릭터는 억제를 어떻게 보여주는가? |
| "마침내" | 누가 먼저 굴복하는가? 교착을 뭐가 깨는가? |
| "날것의" | 실제 감정이 뭔가? |
| "조심스럽게" | 왜? 조심하지 않으면 어떻게 되는가? |
| "~에 얻어맞은 것처럼" | 몸에서 실제로 어떤 느낌인가? |
| 대상 없는 "필요" | 뭐가 필요한가? 누구로부터? 왜? |
| 날씨/풍경으로 여는 문장 | 캐릭터는 어디에 있고 무엇을 하는가? |
| "모든 것이 바뀌었다" | 이 순간이 실제로 그렇게 큰가? |

### 3.6 퇴고 단계 (12단계 검색-교정)

| 단계 | 검색 대상 | 조치 |
|---|---|---|
| 1. 구조 패턴 | "~하고, ~했다" / "뭔가+동사" / "침묵+동사" / "~가 아니라" / "허공에 걸렸다" | 지침에 따라 전부 재작성 |
| 2. 대화 | "말했다"+부사 / "목소리가 떨어지다" / "~같지 않은" | 수식어 제거, 톤을 내용에 내장 |
| 3. 신체 묘사 | 턱/목/손 긴장 / 숨을 내쉬다·삼키다 | 캐릭터별 고유 반응으로 교체 |
| 4. 시간/전환 | "잠시" / "마침내" / "뭔가 바뀌다" | 삭제하거나 구체적 행동으로 |
| 5. 감정 단어 | 날것의 / 조심스럽게 / "그 무게" / "그 필요" | 구체적 감정 명명 또는 행동으로 보여주기 |
| 6. 문장 패턴 | 그리고/하지만으로 시작 / 독립된 "왜냐하면" / 동사 3연속 | 리듬 다양화, 조각 통합 |
| 7. 은유 | "돌처럼" / "얻어맞은 것처럼" / 끌리다·향하다·돌다 / 뜨겁다·차갑다 | 자르거나 직접 묘사로 교체 |
| 8. 결말 | "움직이지 않는다" / "손에 쥔 채" / "아무 말 안 한다" | 행동·결정·결과로 끝내기 |
| 9. 도입/필러 | 날씨·풍경 오프닝 / 가정용 활동 나열 / 감각 나열 | 캐릭터로 시작, 잡무 삭제 |
| 10. 강도 | "모든 게 바뀌었다" / "영원히 부서졌다" | 비례에 맞게 조정 |
| 11. AI 어휘 | 파고들다 / 태피스트리 / 풍경 / 중요한 / 부각시키며 | 구체적이고 캐릭터에 근거한 언어로 |
| 12. 우아한 변주 | "그 나이든 남자" 류 수식어 순환 | 실제 기능이 없으면 이름 사용 |

### 3.7 최종 테스트

- **구체성 테스트:** 이 문장이 다른 이야기, 다른 캐릭터에 그대로 옮겨져도 어색하지 않은가? → 그렇다면 구체성이 부족하다.
- **교체 가능성 테스트:** 이 신체 텔/은유/결말이 아무 캐릭터에게나 붙을 수 있는가? → 그렇다면 캐릭터 고유성이 없다.
- **결과 테스트:** 이 장면/비트/대사 때문에 뭔가 바뀌는가? → 아무것도 안 바뀐다면 장면이 끝난 게 아니다.
- **장식 테스트:** 이 은유/묘사/감각 디테일이 명확하게 하는가, 그냥 꾸미기만 하는가? → 꾸미기만 한다면 잘라낸다.
- **획득 테스트:** 이 감정적 비트가 쌓아올려진 것인가, 그냥 선언된 것인가? → 선언됐다면 기반을 쌓거나 규모를 줄인다.

### 3.8 규칙이 충돌할 때

- **구체성 vs 간결함:** 구체성이 이긴다. 역할을 하는 긴 문장이, 장식만 하는 짧은 문장보다 낫다.
- **캐릭터 보이스 vs 금지 목록:** 특정 캐릭터가 실제로 대사에서 금지된 표현을 쓸 법하다면, 명확한 근거와 함께 드물게 허용한다. 지문(서술)에는 이 예외가 없다.
- **리듬 vs 명료함:** 명료함이 이긴다. 의미를 흐리는 매끄러운 문장보다, 투박해도 전달되는 문장이 낫다.
- **관습 vs 정밀함:** 정밀함이 이긴다. 안 맞는 익숙한 구문보다, 맞는 낯선 구문이 낫다.

### 3.9 운영 원칙

이 가이드의 목적은 **진짜 중요한 이야기를 위한 공간을 비우는 것**이다. 모든 금지 요소는 다음과 같은 더 어렵고 더 나은 작업을 피하게 해주는 지름길이다:

- 실제로 무슨 일이 일어나는지 파악하기
- 이 특정 캐릭터가 어떻게 반응할지 이해하기
- 구조로 긴장을 쌓기 (진술로 선언하지 않기)
- 독자에게 느낄 것을 지시하지 않고, 획득된 감정을 스스로 느끼도록 신뢰하기

금지는 정밀함을 강제하기 위해 있고, 정밀함은 이야기를 위해 봉사한다.

### 3.10 AI 패턴 문제

많은 금지 패턴은 단순히 나쁜 작법을 넘어 **식별 가능한 AI의 흔적**이다.

- **탐지 위험:** 독자는 점점 AI 생성 산문을 알아본다. AI 기원을 드러내는 패턴은 몰입을 깨고 서사 목소리에 대한 신뢰를 해친다.
- **근본 원인은 같다:** AI는 캐릭터·장면·결과에 대한 구체적 지식이 없어서 통계적으로 흔한 패턴에 기본값으로 의존한다. 사람이 같은 패턴을 쓸 때도 같은 오류를 범하는 것이다 — 구체적 의미 대신 일반적 리듬을 대체.

**교정법은 동일하다:** 구체적으로 쓴다. 모든 묘사를 캐릭터의 지각에 근거시킨다. 모든 제스처가 역할을 하게 한다. 결과가 서술로 선언되지 않고 행동에서 자연스럽게 발생하게 한다.

### 3.11 우아한 변주의 함정

이름 대신 "그 주인공" → "그 핵심 인물" → "그 중심 인물"처럼 동의어를 순환하는 건 기계적 회피에 불과하다.

**규칙:** 수식어가 특정한 역할(시점 확립, 감정적 거리감 표시, 권력 관계 이동)을 하지 않는 한 이름을 쓴다.

### 3.12 서술자 거리

AI 서술은 극화하지 않고 분석하는 경향이 있다 — "그녀는 문을 닫았다, 공간이 필요함을 드러내며"처럼, 서술자가 장면 밖으로 나가 의미를 설명해버린다.

**규칙:** 서술은 캐릭터의 지각 안이나 장면의 물리적 현실 안에 머물러야 한다. 서술이 의미를 설명하기 시작하는 순간, 소설은 에세이로 변질된다.

행동에 해석이 필요하다면:
- 그 행동이 충분히 구체적이지 않은 것이니 더 구체적으로 쓰거나
- 그 해석을 서술자 논평으로 두지 않고 캐릭터의 내면으로 옮기거나
- 그 해석은 잘라내고 독자를 신뢰해야 한다
